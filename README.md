# Floresta Ondas

Jogo 2D top-down em Godot 4.7: limpe 3 ondas de slimes na arena.

## Rodar

```bash
godot --path .
```

Ou abra a pasta no Godot Editor e rode a cena Main.

## Controles

- WASD / setas: mover
- Mouse: mirar
- Clique esquerdo / Espaço: atirar

## Sprites

```bash
./tools/generate_sprites.sh
```

Requer ImageMagick (`convert`).
